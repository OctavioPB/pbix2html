This overrides the theme extracted from the .pbix when generating HTML — every mode (snapshot, live, hah) picks it up automatically once saved, no flag needed. It only affects colors and font, nothing else (layout, data, and text are untouched).

Many reports' extracted theme is just the name of one of Power BI's built-in themes (e.g. CY18SU07), with no actual color values stored in the .pbix at all — there's nothing to recover automatically in that case.
